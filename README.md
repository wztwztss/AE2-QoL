# AE2 QoL

> [English](README.en.md) | **简体中文**

**为 GTNH 打造的 AE2 效率增强模组**：把 NEI 配方一键推送进 AE 样板终端、从 NEI 面板直接提取 AE 网络物品、查看每个物品在 AE 网络中的存量与可合成状态、无线传输 AE 网络、自适应电网系统等。

适配：GTNH 2.9.0-beta-1（Minecraft 1.7.10）| 当前版本：**3.18.1-fix18** | 作者：wztwzt

---

## 📦 安装

1. 将 `AE2-QoL-3.18.1-fix18.jar` 放入 `.minecraft/mods/`
2. 确认已安装依赖：AE2（`rv3-beta-977-GTNH`）、ae2fc（`1.5.88-gtnh`）、NotEnoughItems（NEI）
3. 启动游戏。配置会生成在 `config/` 下

> ⚠️ **服务器更新**：3.8.0 及更早版本在专用服务器上使用二合一终端部分功能会被踢出（#74），服务端与客户端请同步更换为 3.8.1+。

**配置文件**（均在 `config/ae2_qof/` 目录，**支持热加载**：直接编辑保存后约 1 秒自动生效，无需重启）：

| 文件 | 作用 |
|---|---|
| `settings.json` | 统一配置文件：`io_port_rate`（强化 IO 端口传输倍率，默认 1024）、`smart_doubling_max_rounds`（智能倍增最大轮数，默认 0=不限，范围 0~2147483647）、`nei_overlay_enabled`（NEI 叠加层开关） |
| `remembered_providers.json` | 记住的"配方 → 供应器"映射，用于自动上传（可自行编辑，格式为配方名→供应器名） |
| `recipe_names.json` | 用户配方映射表（内置 GTNH 47+ 条默认映射，随 jar 打包） |

**OP 管理命令**：

- `/ae2qof reload` —— 立即热重载 `settings.json` + `recipe_names.json`（改完文件不想等 1 秒就用它）
- `/ae2qof status` —— 查看当前生效的配置值
- 服务端需 **OP 权限**（等级 2）；单机 / 局域网主机默认即 OP，可直接使用
- `/apu-overlay` 仍用于快速切换 NEI 叠加层显示（无需 OP）
- ⚠️ `/apu-overlay` 注册于客户端，仅单机 / 局域网主机可用；**专用服务器上请使用终端 GUI 内的 OV 按钮**
- NEI 叠加层开关为**纯客户端本地设置**（多人下各玩家独立，不随服务端配置同步覆盖）

**游戏内配置页面**：暂停菜单 → Mods → AE2 QoL → **Config**，可直接修改 `io_port_rate` / `smart_doubling_max_rounds`（0=不限）/ `nei_overlay_enabled` 并即时应用（多人服务器需 OP 权限，修改会同步给所有客户端并写入服务端 `settings.json`）。

## ✨ 功能总览

### 1. NEI 样板上传 / 撤回 / 交换（样板终端 GUI 内 4 个按钮）

在 **AE2 标准/扩展样板终端** 界面右上角出现 4 个按钮：**↑ 上传**（把当前样板输出槽中的编码样板自动上传到网络中的接口/总成）、**← 撤回**（从网络取回最后一个匹配的编码样板）、**⇄ 交换**（交换主产物/副产物位置）、**OV**（开关 NEI 配方页/书签的 AE 叠加层显示）。

上传时自动按配方匹配供应器（三策略：唯一供应器直接传 → 记住的供应器 → 打开选择界面手动选）。支持标准编码样板、终极编码样板、ae2fc 流体编码样板。

**中文名称识别**（3.18.1-fix17/18）：供应器选择界面的搜索框现在正确显示中文机器名（如"大型化学反应釜"而非英文 id），内置映射表覆盖 313 种配方类型（GT/GT++/GTNL/BartWorks/TST 等所有 mod），映射表查不到时自动用 NEI 提供的中文名兜底。

### 2. NEI 面板取物品 / 合成下单

- **Shift + 左键** 点击 NEI 物品面板：从 AE 网络取出一组该物品到背包（自动放入）；无存量但可合成则跳转合成
- **鼠标中键** 点击 NEI 物品面板：打开 AE2 合成数量确认界面——**网络中有该物品的合成样板即可下单**（无需网络实际存有该物品）

操作结果会在聊天栏提示：成功 / 未找到 / 不可合成 / 背包已满。

### 2.5 合成产物置顶行（pin，3.14.0 重做）

下单后，该订单的产物自动**钉选到终端最上方的独立行**（pin 行）——原物品网格整体下移，不遮挡任何内容：

- 置顶条目显示该物品在 ME 网络中的**全部存量**（不只是本次合成数量）
- 产物种类超过一行时**自动扩展行数**（最多 3 行，如 18 种占两行）；减少时自动回落
- **标准 ME 终端 / 原生无线终端 / 终端部件**默认开启 1 行；终端设置（齿轮 → Pins Rows）可调行数或**完全关闭**（3.15.0 修复开关失效）；另有 `settings.json` 总开关 `pin_row_enabled`
- 右上角「合成完成」横幅保留不变

### 3. NEI 物品悬浮提示（tooltip）

- **青色数量**：该物品在 AE 网络中的存量（支持 K/M/G/T/P/E 科学计数）
- **绿色 +Craft**：该物品当前可通过 AE 网络合成
- **流体直接显示**：桶、流体单元等容器物品直接显示流体本身的数量（如 `4.5P mB 蒸馏水`），而非容器个数

### 4. NEI 书签面板数量叠加

NEI 左侧书签面板中的物品右下角会叠加显示网络存量 / 可合成标记。

### 5. 合成完成通知（3.15.0 对齐原生样式）

AE 合成 CPU 完成订单时，屏幕右上角滑入 **AE2 原生样式横幅**（原版成就贴图+滑入动画）：

- 显示成品图标 + **中文标题「自动合成完成」** + N 物品名, 耗时 HH:mm:ss（任务实际耗时）
- 播放升级音效；多订单排队依次展示
- **自动推送给下单玩家**，无需像原生通知那样每次去 CPU 界面点「关注」

### 6. 合成重新规划（Replan）

在 AE2 **合成确认界面** 中多一个 **重新规划** 按钮：点击后对当前模拟的合成任务重新分配一次流程。

### 7. 强化 IO 端口（`ex_io_port`）

外观与 AE2 原生一致，但**每次传输的物品数量放大 1024 倍**（可在 `config/ae2_qof/settings.json` 中 `io_port_rate` 调整，改完自动热加载）。

### 8. 无限水与岩浆磁盘

放入 ME 驱动器后提供**近乎无限的水与岩浆**（每种 ≈ 4.5×10^15）。合成配方：水桶 + 岩浆桶左右放置，中间及两侧格留空。

### 9. 无线收发器 + 无线连接器

- **无线收发器**（方块）：把一块 ME 网络的物品/流体接入无线频道；右键打开 GUI 设置频道与模式（发送端/接收端）
- **无线连接器**（工具）：把 ME 设备（接口、终端、机器等）绑定到无线频道，实现远程无线直连

**使用流程**：放置两个收发器（一发一收，同一频道）→ 两块网络无线互通；**Shift+右键** 发送端用连接器绑定频道；**右键** 任意 ME 设备接入网络，再次右键解除。支持**跨维度**连接。收发器 GUI 支持添加/删除频道、切换模式、高亮显示已连接方块（红色边框）。

### 10. 石英切割刀复制名称

拿着 **石英切割刀**（Quartz Knife），在命名界面 **Shift+右键** 点击方块/AE 部件/GT 机器 → 自动把目标名称写入刀名并复制到剪贴板。

### 11. F 键搜索填充

在 AE2 / ae2fc 终端界面中，把鼠标悬浮在某物品上按 **F** 键 → 自动把该物品名称填入搜索框。

### 12. NEI 叠加层开关

- 命令：`/apu-overlay`（切换 NEI 配方页/书签叠加层显示，仅单机 / 局域网主机可用，专用服请用 OV 按钮）
- 或样板终端 GUI 中的 **OV** 按钮
- 持久化到 `config/ae2_qof/settings.json`（`nei_overlay_enabled`，纯客户端本地设置，多人下各玩家独立）

### 13. 智能倍增（Smart Doubling）

**ME 接口**的 GUI 左侧新增**智能倍增**复选框（循环箭头按钮）。勾选后，合成 CPU 会把挂在接口上的样板**一次性推送 N 轮**材料，机器连做 N 轮再回来补料，补料不再逐轮等待，大幅加快 GT 流水线。

- **N 的确定**：`N = min(剩余合成轮数, smart_doubling_max_rounds, 各输入槽可提取量/单轮量, 功率可支付轮数, 机器可吞轮数)`；GT/PH 仓由 CPU 侧模拟探测，ProgrammableHatches 双口输入仓内部按缓冲空间自取（`pushPatternMulti`）
- **适用介质**：ME 接口、GT 样板输入总成/输入总线 (ME)（2714/2715）、GTNL 超级样板输入总成 (ME)（21504/21505，3.9.0 起）、ProgrammableHatches 双口输入仓、GTNL 超级二合一 ME 接口
- **默认上限**：0 = 不限（一次发配剩余全部轮数；`config/ae2_qof/settings.json` 的 `smart_doubling_max_rounds`，范围 0~2147483647，改完自动热加载，也可在「Mods → AE2 QoL → Config」页面修改）
- **安全边界**（自动退回逐轮推送，与原版行为完全一致）：假合成、流体接口、阻塞/智能阻塞模式、接口有滞留未推送物品、GT 直接吃样板的机器（`acceptsPlans`）；材料不足/功率不足时**按可提取轮数钳制 N**（而非整体放弃推送）
- **能耗**：按实际推送轮数一次扣取；产出与剩余轮数按实际轮数记账，不会超产或丢物

### 14. 样板 + 接口二合一终端（独立方块「样板与接口终端」）

新增独立有线方块**样板与接口终端**（Pattern & Interface Terminal），把**样板编码面板**与**接口管理列表**合并在同一界面——接口样板管理与样板编码同一界面完成，无需再单独打开样板终端。放置方块右键打开（需要 AE 网络）。

- **面板样式**：AE2Things 原生风格——合成/处理双 tab、原生图标按钮（编码/清空/×2/替代/备份替代/反转）、处理模式 4×4×2 页网格（滚动条翻页，反转按钮切换输入/输出列方向），合成模式为 3×3 + 结果槽
- **顶部按钮**：`↑`（上传，把已编码样板自动上传到网络中的接口/总成，Shift+点击强制打开供应器选择界面）/ `←`（召回，取回最后一个匹配样板）/ `⇄`（交换，轮换主产物/副产物位置）/ `AM`（上传至 GTNL 装配矩阵，合成模式且安装 GTNL 时显示）/ `OV`（NEI 叠加层开关）
- **操作**：面板内可直接放入物品构成配方，点 `编` 编码；点 `清` 清空面板；`×2` 输出倍率加倍；处理配方通过 `替`/`备` 设置替代与备份替代
- **样板回读**（3.6.0）：把编码好的样板放回 OUT 槽自动解码回填面板——输入/输出/模式/替代开关一并恢复，支持 GT 终极样板与流体（还原为 GT 展示物品），供应器映射保留，可直接二次编辑后再编码
- **编辑快照**（3.6.0）：关闭终端时自动保存面板全部格子与模式，重新打开完整恢复
- **PH 编程工具箱 MK.II 适配**（3.6.0）：背包携带工具箱时 NEI 转写配方自动把不消耗催化剂替换为编程电路（兜底模式追加归零电路）；PH 未安装时零影响
- **中键数量编辑**：中键点击面板槽位弹出数量编辑框（+1/+10/+100/+1000 与 ×2/×8/×64/×512，Shift 切换；数量无上限）；Shift+中键重命名物品；输出格不可编辑
- **交互细节**：面板槽点击与拖拽放置同 AE2 原生终端；滚动条点击/滚轮翻页；面板区域点击优先于接口列表
- **面板部件形态**（3.7.0）：新物品「样板与接口二合一终端面板」可安装到 AE2 线缆任意面（外观同原版 ME 终端部件，需通道+耗电），GUI 与方块形态完全一致；合成：铁锭 + 二合一终端方块
- **无线手持形态**（3.7.0）：新物品「无线二合一终端」随时随地右键打开完整二合一界面，**支持跨维度**；绑定方式同原版——放入 ME 安全终端编码槽完成绑定，安全站被拆即失效；免电设计；权限仍由安全站生物卡强制；合成见配方（钻石块 + 红石 + 铁锭等）

### 15. ME 任务检测器（BetterQuesting 联动，3.11.0）

新增方块**ME 任务检测器**：接入 ME 网络后，网络中存储的物品会自动完成 BetterQuesting 的**检索型任务**（不消耗类）——任务物品存进网络即视为达标，无需手动取出或跑提交站。

- **绑定放置者**：进度按放置者计算，自动兼容 BQ 组队共享进度；拆下重放可重新绑定
- **零消耗保证**：只调用 BQ 官方只读检测钩子，绝不从网络扣走任何物品；消耗型任务完全不受影响
- 每秒检测一次；断电/断频道暂停；绑定玩家离线时跳过
- WAILA/JADE 显示绑定玩家与网络状态；未安装 BetterQuesting 时无效果

### 16. 无限存储元件（吞并 AE2InfinityCell，3.12.0）

原独立模组 **AE2 Infinity Cell**（dancing snow 作，MIT）整体并入本 jar：新增物品**无限存储元件**——物品、流体、源质三通道近乎无限存储，内容保存在世界存档中（元件仅存 UUID 引用），复制出的元件共享同一份库存。

- 放入 ME 驱动器/ME 存储箱即用；NEI 内对元件按 `U` 打开「Infinity Cell View」分页浏览全部内容
- ⚠️ 本 jar 与原版 aeinfinitycell 模组**互斥**：安装前必须移除原 jar；旧磁盘与存档数据零迁移无缝兼容
- **悬停统计**（3.13.0）：悬停元件显示总计/物品/流体/源质明细与字节估算；默认字母单位（12.34M），按住 Ctrl 切科学计数法
- AppEU 能量通道未包含

### 17. 万能维护仓（3.16.0）

新增 GT 仓室形态物品**万能维护仓**：放置于多方块结构维护槽位，提供三重能力：

- **维护绕过**：所有多方块机器永远无维护问题（Mixin 全局注入 `shouldCheckMaintenance()` 返回 false）
- **无线能源**：放置时绑定放置者 UUID，定期从全球无线电网拉取 EU 到本地存储（需提前通过其他方式向无线电网注入 EU）
- **电路板并行映射**：插入 GT 电路板设置并行数，公式为 4^level（LV=4, MV=16, HV=64, EV=256, ...）

配方：铁锭 ×4 + 玻璃 ×2 + 红石 ×2 + LV 电路板（3×3）

### 18. GT 无线 EU 网格（3.17.0）

通过 GT 仓室实现 EU 能源无线传输，与 AE 网络无关，纯粹用于 GT 机器供电：

- **无线输入仓**（ID 32111）：放置时绑定放置者 UUID，定期从无线电网拉取 EU 到本地存储
- **无线输出仓**（ID 32110）：将本地 EU 注入无线电网

### 19. 自适应电网系统（3.18.0+）

新增 GT 仓室形态的自适应电网系统，通过**网络数据棒**配置实现多仓室共享电网：

- **自适应电网终端**（ID 32100）：5-Tab GUI 管理网络
  - **状态 Tab**：频率、所有者（玩家名）、4 种仓的加载数量/电压/电流实时显示
  - **设置 Tab**：4 个仓插槽（动力仓/能源仓/激光源仓/激光靶仓），各放 64 个物品自动配置
  - **监控 Tab**：电网总电量、1h/10min 能量变化、预计耗空时间、瞬时输入/输出速率，支持常规/科学/KMG 三种数字格式
  - **频率设置 Tab**：宽幅频率输入（范围 -2147483648 ~ 2147483647），修改时自动迁移仓室
  - **子仓列表 Tab**：按真实流量降序显示所有已绑定仓室，每行显示机器图标+机器名+电压+电流+EU/t，末尾"定位"按钮（左键高亮 10 秒、Shift+左键传送，支持跨维度）
- **自适应电网能量仓**（ID 32102）：自动匹配终端电压等级，从无线电网拉取 EU
- **自适应电网激光源仓**（ID 32103）：激光输出仓，双倍电压
- **自适应电网动力仓**（ID 32104）：动力输出仓，注入 EU 到电网
- **自适应电网激光靶仓**（ID 32105）：激光接收靶仓，双倍电压
- **网络数据棒**（ItemNetworkDataStick）：Shift+右键终端初始化并写入网络配置，右键仓室绑定，右键终端读取配置

**团队共享**：同 SpaceProjectManager 团队成员可共享同一网络（共用数据棒、共用终端），传送权限也按团队判断。

**仓室定位**：子仓列表中点击"定位"按钮可高亮仓室（按类型着色：动力=橙/能量=蓝/激光源=紫/激光靶=黄，5px 线框 10 秒）或直接传送（支持跨维度）。

**多方块主机识别**：自适应仓室自动识别所贴附的 GT 多方块主机——通过全局注册表（Mixin 自动注册所有 MTEMultiBlockBase 主机）+ 中心/半径匹配，子仓列表正确显示主机名称和图标。

**使用流程**：放置自适应终端 → Shift+右键数据棒写入配置 → 右键仓室绑定 → 右键终端读取配置 → 仓室自动适配等级

## 🙏 致谢

本模组由 [**AE2-Auto-Pattern-Upload**](https://github.com/GaLicn/AE2-Auto-Pattern-Upload/)（作者 GaLicn）改造而来，最初版本的上传与 F 键搜索功能直接取自原项目，并针对 GTNH 2.9.0 进行了适配，特此向原作者致谢。

开发中还参考了大量其他模组的代码与材质，主要来源如下（完整明细与许可证核对见 **`CREDITS.md`**）：

### 代码参考
- **Applied Energistics 2 GTNH**（`Applied-Energistics-2-Unofficial`）—— AE 网络、存储、网格、合成逻辑几乎全部直接调用其 API 与内部类；无限水岩浆磁盘继承 `AEBaseInfiniteCell`、复用 `CreativeCellInventory` 机制
- **AE-Wireless-Transceiver**（作者：小飘 / mynamexiaopiao）—— 无线收发器方块/终端/连接器整套实现（已通过 B 站联系作者确认借用许可）
- **AE2FluidCraft-Rework**（ae2fc）—— 流体样板（`ItemFluidEncodedPattern`）、纯流体识别
- **AE2Things**（asdflj）—— 强化 IO 端口、无限流体磁盘、创意单元等概念参考
- **NotEnoughItems**（NEI）—— NEI 配方页 AE 角标、tooltip 注入
- **Waila** —— 无线收发器等方块的高亮显示支持
- 其他参考：`GT-Not-Leisure`、`GT5-Unofficial`、`GTLCore`、`Programmable-Hatches`、`ExtendedAE_Plus`、`ExampleMod1.7.10`（GTNH 模板）等

### 材质参考
- **AE-Wireless-Transceiver**（作者：小飘 / mynamexiaopiao；贴图作者：麦淇淋 / @麦淇淋）—— 无线收发器方块贴图、`de.png` / `de1.png` / `widgets.png`、无线连接器贴图（已获作者许可）

# 产线管理器（Production Line Manager）

在库存统计终端新增第 3 个页签「产线」：把团队已加载区块内的 GT 多方块机器按"步骤"组织成一条产线，实时看每步在产/停机的工作状态、主产物与累计/速率。

## 预置产线（推荐入口）

产线页顶栏 →【预置产线】→ 点击名称即建线（当前内置：硅岩 / 独居石主线 / 氟碳镧铈主线 / 钐精粉主线 / 海晶酸线 / 湿件线 / 异氙线），建线后照常绑定机器或用 NEI/编辑器修改。

## 快速开始

1. 产线页顶栏【+新建产线】建线（须在 ServerUtilities **团队**里，无团队会提示）；
2. 点产线行选中 → 点步骤行打开子面板；
3. 子面板里对步骤可以：**暂停/恢复（真停机）**、写入手持绑定卡、查看候选机器并绑定/解绑；
4. 底部汇总面板显示外部输入/末端产物的累计（BigInteger 跨重启持久）与约速率（每 10 秒刷新），并显示 wiki `start[]` 期望边界。

## 绑定机器的两种方式

- **候选面板点选**（推荐）：团队声明区块内已加载的 GT 多方块 = 候选；一台机器只属于一条产线。
- **产线绑定卡**（兜底）：先在终端里选中产线+步骤 →【写入手持绑定卡】→ 手持卡 `Shift+右键` 目标机器。生存配方：4 纸 + 1 铁锭。

## 停机语义（真停机）

暂停（步骤/整线）直接对绑定机器写入 GT `disableWorking()`；恢复写 `enableWorking()`。解绑/删线一律恢复可工作。区块未加载时按"离线"显示，机器复活后由采样轮自动把停机位重压回去。

## 汇总口径

- 总输入 = 没有任何步骤产出的物品；总输出 = 没有任何步骤消耗的物品（分支切换只影响视图，4.2.0 再补重算）。
- 累计键（BigInteger）跨重启持久；速率为 10 秒窗口，环形 180 点（30 分钟）。
- 采样只对"打开过界面的活跃产线"（≤16 条 F IFO），单次预算 3ms、连败退避 5 分钟。

## 权限与红色线

- 新建/编辑/绑定/暂停 = 团队成员；产线归属**创建者所属团队**。
- 每团队 16 条产线、单产线 64 步。
- 未装 ServerUtilities 时整页禁用（三态日志：已启用/未检测到/失败）。

# 智能通配样板（Smart Wildcard Pattern）

**一张样板覆盖一整类配方**。例如「1×任意锭 → 1×对应板」：你只需要放**一张**样板，
它会在机器建立样板索引时自动展开成「1 铁锭→1 铁板」「1 铜锭→1 铜板」……各自**合法**的普通样板，
因此现有所有样板总成都能识别、机器也照常匹配。

## 与旧做法（通配符模组 / 一键生成同类样板）的区别

| | 旧做法 | 智能通配样板 |
|---|---|---|
| 样板数量 | 通配符模组 1 张但要手写匹配串；生成器要一次产出成百上千张 | **1 张**，规则从 NEI 配方**自动推导** |
| 配置方式 | 手写 `ingot*` 之类匹配串、拖物品 | 在 NEI 里对着配方**点加号** |
| 编程电路 | 只能把电路当普通物品拖进去，容易与消耗语义冲突 | **内置电路**（1~24），机器工作时自动写入虚拟电路槽读取 |
| 排除 | 只有全局/规则两级字符串 | 预览里**逐条点「排除」**即进该样板自己的黑名单 |
| 展开上限 | 无上界（服务端网络钩子主路径上展开，是卡服点） | 默认 **512**、可配置、超限**截断并记 WARN** |

## 制作流程（三步）

1. 取出「智能通配样板」物品（AE2 QoL 创造标签页；合成配方见下）；
2. **右键**它打开配置界面（三页 + 电路页）：
   - **规则**页：显示本样板当前的规则；
   - **预览**页：逐条列出本样板覆盖到的具体候选，每行右侧有「排除」按钮 —— 点一下就把这个候选写进**黑名单**（正是"生成好之后手动排除"）；预览用的是与机器完全**同一个展开器**，所以预览能出来的、机器就一定能合成；
   - **黑名单**页：手动补/删排除串（支持 `*` `?` 通配）；
   - **电路**页：选 1~24 电路（或「清除（继承）」）＋把铸模/模头/透镜这类**其他不消耗物品**记进样板。
3. 在 NEI 里打开你要覆盖的配方（例如卷板机「1 锭 → 1 板」），**点加号**：
   界面会当场推导出规则与配方模板并刷新；确认无误后点**保存**，由服务端写入样板 NBT。

之后把这张样板放进任意样板总成即可。

## 支持的总成

- GT **样板输入总成 / 样板输入总线（ME）**（2714 / 2715；从属机自动跟随主机）
- **PH 家族**：编程样板输入总成（22069）、MK.II（22179）、以及本模组的 **MK.III（32108）**（144 槽）
- **GTNL 超级样板总成**（21504 / 21505）
- **AE2 ME 接口**（方块 / 线缆面板）

## 编程电路（内置电路）

- 在「电路」页选 1~24；样板被机器读取时，本模组会把这个电路号写进**机器的虚拟电路槽**
  （GT 官方接口 `IConfigurationCircuitSupport.getCircuitSlot()` + `GTUtility.getIntegratedCircuit()`）。
- 优先级：**样板自带 > 槽位设置 > 整机电路**。样板**没有**设置电路时，本模组**不会动**机器原有的电路槽。
- 一个机器里若有多张带不同电路的样板，机器级电路槽只有一个 ⇒ 以最后一次写入为准（这是 GT 电路槽本身的限制）。

## 配置项

| 键 | 说明 | 默认 |
|---|---|---|
| `smart_wildcard_expand_cap` | 单张通配样板最多展开多少个候选。超限会**截断并在日志里记 WARN**（不会静默少给） | `512` |

## 已知边界

- 一张样板覆盖**一个配方类**（不是"任意配方"）：规则来自你推导的那条配方，矿辞优先、无矿辞时退化为显示名精确匹配；
- 流体以占位物品出现在 NEI 配方里时会被**跳过**（不会拿流体占位物品去推导矿辞）；
- 展开发生在**样板索引期**（放样板/换样板/读档时），不是每 tick；上限内不会造成卡服；
- 「Shift+中键点样板槽直接弹出电路列表」这一手势仍在开发中，当前请用**右键样板的「电路」页**（功能等价）。

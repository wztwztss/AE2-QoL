# 合成通知与重新规划（功能 5/6）

让长耗时合成订单"放下不管、完成即知"，材料变化时也不用重下订单。

## 合成完成通知（功能 5）

向 CPU 提交合成订单后，该订单**完成时**屏幕右上角滑入横幅：

- 显示成品图标 + `x数量` + 物品名
- 播放升级音效提示
- 多个订单排队依次展示，数秒后自动消失

只通知订单发起者本人；离线期间完成的订单不会补发

## 合成产物置顶行（pin）

下单后，该订单的产物会自动**钉选到终端最上方的独立行**（pin 行），方便盯产与取货：

- 置顶条目显示的是该物品在 ME 网络中的**全部存量**（不只是本次合成数量）
- 独立一行渲染，原有物品网格自动下移，不遮挡任何内容
- 产物种类多时自动扩展行数（最多 3 行）；也可在终端设置中手动固定行数
- **无线终端 / 二合一终端 / 标准 ME 终端**均支持（标准终端需在终端设置中将 Pins Rows 设为非关闭）。

## 合成重新规划 Replan（功能 6）

场景：下单后网络里的材料变了（补了货 / 用掉了部分中间产物），原版 AE2 的订单会卡在缺料状态。

操作：在 **确认合成界面（GuiCraftConfirm）** 中会出现重新规划入口——点击后本 mod 对已完成模拟的 job 重新提交 `beginCraftingJob`，CPU 按当前库存重排制作分支。

- 无需取消再重新下单
- 保留原有订单数量设置

> 适用前提：订单处于已模拟/等待材料状态。已全部完成的订单无意义。

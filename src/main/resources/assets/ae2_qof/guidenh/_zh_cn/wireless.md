# 无线收发器 + 无线连接器

让 ME 网络"隔空"组网：无需物理拉线即可把两个（或多个）网络桥接起来，**收发器对支持跨维度**。

## 组件

| 物品/方块 | 角色 |
|---|---|
| **无线收发器**（方块） | 频道的发送端或接收端，GUI 内配置 |
| **无线连接器**（物品） | 把普通 AE 设备（线缆、机器）远程绑定到某个频道 |

## 收发器使用流程

1. 放置两个无线收发器（可在不同维度）。
2. 打开 GUI，在输入框输入频道名并点 **添加** 创建全局频道。
3. A 端选频道后点 **设为发送端**；B 端选同一频道点 **设为接收端**——自动建立连接。
4. **断开连接** 按钮进入暂停态（保留配置）；**高亮连接** 可在世界中显示已绑定的方块位置。

## 连接器使用流程

1. 潜行 + 右键任意收发器，把它的频道"吸入"连接器（提示已绑定）。
2. 右键网络中的任意 AE 设备（线缆/机器）——该设备所在网格即接入该频道的远端网络。
3. 对已绑定的设备再次右键 = 解除绑定。
4. 各维度的设备可分别绑定到同一频道，由收发器链路跨维度桥接。

## 频道管理

- 全局频道所有玩家可见；删除频道会强制断开其全部发送端连接
- GUI 顶部的 **添加 / 移除 / 高亮 / 发送端 / 接收端 / 断开** 按钮均有悬停说明

## 合成

见配方标签页（收发器：铁+金+红石；连接器：铁+金+红石+钻石）。

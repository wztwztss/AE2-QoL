# 批量样板生成器（Pattern Generator）

当"一张通配样板覆盖一类配方"表达不了你的需求时（例如**多个输入各自是不同材料**），
用这个生成器按 **GT RecipeMap** 一次性产出**一堆普通样板** —— 它们和手写编码的样板完全等价，
任何样板总成都认。

## 用法（三步）

1. 取出「批量样板生成器」物品（配方 = 1 张 AE2 空白样板；也可从 AE2 QoL 创造标签取）；
2. **右键**打开界面，填写：
   - **配方 Map**：RecipeMap 的 id 或其片段（如 `rolling` 就能匹配到 `gt.recipe.rolling`；
     片段命中多个时**用第一个并在日志里列出其余**，绝不静默挑选）；
   - **过滤器**（全部"留空 = 不启用"，匹配串支持 `*` 与 `?`，可同时匹配**显示名**与**矿辞名**）：
     - 输入排除 / 输出排除：命中即跳过该配方；
     - 输入矿辞 / 输出矿辞：配方必须包含命中的输入/输出；
     - NC 物品：配方必须包含该**不消耗**物品（GT 配方里 `stackSize = 0` 的那些，例如铸模、模头、透镜）；
   - **数量上限**：本次最多产出多少张样板（默认 512）。
3. 点「生成样板」：**服务端**扫描该 RecipeMap 并产出样板，产物**进背包**（放不下会掉在脚下并提示）。

## 结果怎么看

聊天栏与日志都会给出**全量计数**，不会只告诉你"生成了 N 张"：

```
[AE2QoL] 样板生成：player=… stored=52 dropped=0 map=gt.recipe.rolling seen=120 produced=52 skippedFluid=8 filtered=60 truncated=0
```

- `seen` 扫描到的启用配方数；`produced` 实际产出；`skippedFluid` 因**含流体**跳过（本版不支持流体样板）；
- `filtered` 被你的过滤器排除；`truncated` 因触到上限被截断（会额外记一条 WARN）。

## 与智能通配样板怎么选

| 场景 | 用哪个 |
|---|---|
| 同一类配方（如"任意锭 → 对应板"），想**只占一个样板槽** | 智能通配样板 |
| 多输入、不同材料、需要精确到某一条配方 | 本生成器（产出一堆普通样板） |
| 想一次拿到某个机器**全部**配方的样板 | 本生成器 |

# 自适应电网系统

GT 仓室形态的**自适应能源网络**，通过数据棒配置网络 ID，实现多仓室共享同一套电压/电流/频率设置。仓室自动匹配终端设定的等级，无需手动逐个调整。

## 组件一览

| 组件 | ID | 功能 |
|---|---|---|
| 自适应终端 | 32100 | 网络主控，右键打开 GUI 管理网络 |
| 自适配输入仓 | 32102 | 能源输入，自动匹配电压等级和电流 |
| 自适配激光源仓 | 32103 | 激光输出，自动匹配等级 |
| 自适配动力仓 | 32104 | 动力输出（EU 输出），自动匹配等级 |
| 自适配激光靶仓 | 32105 | 激光接收，自动匹配等级 |
| 网络数据棒 | — | 配置工具，写入/读取/绑定网络配置 |

## 终端 GUI（3 个标签页）

### 主状态

- 显示当前网络 ID、已绑定仓室列表
- 每个仓室显示：类型、坐标、维度、当前电压/电流、负载状态
- 支持点击仓室**传送**（需权限）和**高亮**（世界中红框显示）

### 自适配设置

- 设置目标电压等级（LV/MV/HV/EV/IV/LuV/ZPM/UV/...）
- 设置目标电流（1A/2A/4A/8A/16A）
- 所有绑定的仓室自动适配到设定值

### 频率设置

- 设置激光传输频率
- 激光源仓和激光靶仓需频率匹配才能传输

## 数据棒使用

| 操作 | 效果 |
|---|---|
| Shift + 右键终端 | 初始化/写入网络配置到数据棒 |
| 右键仓室 | 将仓室绑定到数据棒中的网络 |
| 右键终端 | 从数据棒读取配置并更新终端 |

## 快速上手

1. **放置终端**：放一个自适应终端，右键打开 GUI
2. **配置网络**：在"自适配设置"中设定电压等级和电流
3. **写入数据棒**：Shift + 右键终端，把配置写入网络数据棒
4. **绑定仓室**：拿着数据棒右键各个仓室，它们会自动加入网络
5. **验证**：右键终端打开 GUI，在"主状态"页查看所有已绑定仓室
6. **工作**：仓室自动适配到设定的电压/电流等级，开始传输能源

## 多人与权限

- 每个网络由**放置者 UUID** 标识
- 只有网络所有者可以修改设置和传送
- 团队成员可共享网络（需在终端中授权）
- 支持**跨维度**仓室绑定和查看

## 监控功能

终端"主状态"页实时显示：

- 每个仓室的**真实负载**（EU/t + V + A）
- 仓室归属（所有者名称）
- 维度和坐标
- 电量耗尽时间估算
- 彩色 Tier 标识（不同电压等级不同颜色）

## 合成

各组件配方见 NEI 配方标签。

## 注意

- 终端本身不传输能源，只做配置和监控
- 仓室需绑定到终端网络后才会自适应
- 电压等级不匹配时仓室会停机并提示
- 激光传输需要源仓和靶仓频率一致
- 退出存档重进后绑定自动恢复，无需重新绑定

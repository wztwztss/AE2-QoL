# 自适应电网系统

GT 仓室形态的**自适应能源网络**，通过数据棒配置网络 ID，实现多仓室共享同一套电压/电流/频率设置。仓室自动匹配终端设定的等级，无需手动逐个调整。

## 组件一览

| 组件 | ID | 功能 |
|---|---|---|
| 自适应终端 | 32106 | 网络主控，右键打开 GUI 管理网络 |
| 自适配输入仓 | 32102 | 能源输入，自动匹配电压等级和电流 |
| 自适配激光源仓 | 32103 | 激光输出，自动匹配等级 |
| 自适配动力仓 | 32104 | 动力输出（EU 输出），自动匹配等级 |
| 自适配激光靶仓 | 32105 | 激光接收，自动匹配等级 |
| 网络数据棒 | — | 配置工具，写入/读取/绑定网络配置 |

## 终端 GUI（5 个标签页：主状态 / 自适配设置 / 频率设置 / 电网监控 / 子仓列表）

### 主状态

- 显示当前网络 ID、四类仓的加载数量/电压/电流
- 支持在**子仓列表**里对目标点【定位】（左键高亮 / Shift 传送，需权限）

### 自适配设置（网络仓室槽位）

- 设置目标电压等级与目标电流；所有绑定的仓室自动适配到设定值
- 四个槽位（动力仓 / 能源仓 / 激光源仓 / 激光靶仓）各放入 **64 个同类仓**即可自动套用该类仓的规格
- **规格从哪来（3.32.0-fix1）**：本模组自己的四个仓套用**该类的出厂额定**（能源/动力 **1A**、激光 **256A**）；
  TecTech 的激光源/靶仓取它的**评级安培**（取 `maxAmperes` 评级字段，不用带 ×1.25 的运行时方法值）
- **手动优先**：你在终端上改的档位/安培**只在槽位内容发生变化时才被重算**，平时不会被周期覆盖
- **身份按类别判定（3.32.0-fix2）**：槽位接受**整类**仓，而不是只认我们自己的四个：
  能源仓槽 = `MTEHatchEnergy` 系（含 GT 分级能源仓、GT 无线能源仓）+ TecTech 多安培能源族（4/16/64安能源仓、无线能源仓、激光靶仓）；
  动力仓槽 = `MTEHatchDynamo` 系（含 GT 分级动力仓、TecTech 多安培动力仓、TecTech 激光源仓）；
  激光源仓槽 = 我们的自适应电网激光仓 + TecTech 激光源仓；激光靶仓槽 = 我们的激光靶仓 + TecTech 激光靶仓。
  **机械外壳、GT 箱体等非仓类是拒收的**（旧版会因 `maxEUInput()=V[mTier]>0` 把外壳混进来）
- 完整可识别名单（含 ID）见仓库文档 `docs/ADAPTIVE_HATCH_WHITELIST.md`

### 频率设置

- 设置激光传输频率
- 激光源仓和激光靶仓需频率匹配才能传输

### 子仓列表（3.32.0 重做）

- **一行 = 一台主机（多方块机器），不再是一台仓**：主机名与图标由客户端按 MTE id 本地化解析
  （所以在专用服务器上也显示中文）
- 每行第一眼看到的是【**运行 / 待机**】标签 + **实测流量**（我们自己的仓量到的真实吞吐，停机即为 0）；
  第二行是 `N 仓 · 入/出 · 额定功率`
- ⚠️ **GT 的配方 EUt（`mEUt`）不在"耗电"位置显示**：它是**配方口径**且**停机后不清零**，
  只有当机器**在运行**时才会以「配方」名义附在第二行；停机时显示「待机 · 实测 0 EU/t」（3.32.0-fix3 起）
- 列表按**实测流量**排序：真正在干活的机器排在前面，待机的自然沉到底部
- 悬停整行可展开**逐仓明细**（哪一类仓、档位、安培、额定/实测、坐标）
- 归属认不出来的仓**不会消失**，会归到「未识别主机」一组单独显示
- 【定位】定位的是**主机**：左键高亮、Shift 传送到主机附近（自动寻找可站立落点，找不到会提示并取消）
- **玩家背包**在面板底部（3.32.0-fix3 起面板已为它预留位置，不会再压住列表）
- **TecTech 激光仓也纳入统计与配置**：只统计"已接入我们电网的主机"上的激光源/靶仓，
  并会按该类仓的评级**周期写入安培**（它们的安培不写存档，所以必须周期重写）。
  ⚠️ 已知限制：档位改不了（由物品本身决定）；写入会覆盖你在 TecTech 自己 GUI 里设的手动安培

## 数据棒使用

| 操作 | 效果 |
|---|---|
| Shift + 右键终端 | 初始化/写入网络配置到数据棒 |
| 右键仓室 | 将仓室绑定到数据棒中的网络 |
| 右键终端 | 从数据棒读取配置并更新终端 |

## 快速上手

1. **放置终端**：放一个自适应终端，右键打开 GUI
2. **配置网络**：在"自适配设置"中设定电压等级和电流
3. **写入数据棒**：Shift + 右键终端，把配置写入网络数据棒
4. **绑定仓室**：拿着数据棒右键各个仓室，它们会自动加入网络
5. **验证**：右键终端打开 GUI，在"主状态"页查看所有已绑定仓室
6. **工作**：仓室自动适配到设定的电压/电流等级，开始传输能源

## 多人与权限

- 每个网络由**放置者 UUID** 标识
- 只有网络所有者可以修改设置和传送
- 团队成员可共享网络（需在终端中授权）
- 支持**跨维度**仓室绑定和查看

## 监控功能

终端"主状态"页实时显示：

- 每个仓室的**真实负载**（EU/t + V + A）
- 仓室归属（所有者名称）
- 维度和坐标
- 电量耗尽时间估算
- 彩色 Tier 标识（不同电压等级不同颜色）

## 合成

各组件配方见 NEI 配方标签。

## 注意

- 终端本身不传输能源，只做配置和监控
- 仓室需绑定到终端网络后才会自适应
- 电压等级不匹配时仓室会停机并提示
- 激光传输需要源仓和靶仓频率一致
- 退出存档重进后绑定自动恢复，无需重新绑定
- **主机识别**：终端用 GT 各多方块自己记录的仓清单来反查"这台仓属于哪台机器"，因此**不依赖加载顺序**；
  结构未成型或不属于任何多方块的仓会显示在「未识别主机」一组
- 列表里的**主机耗电**是 GT 的实时值；一台机器同时有输入与输出仓时，正负号各自含义以 tooltip 明细为准

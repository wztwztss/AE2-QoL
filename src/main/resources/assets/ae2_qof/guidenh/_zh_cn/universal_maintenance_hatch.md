# 万能维护仓

GT 多方块结构的维护槽位专用仓室，提供**三重能力**：维护绕过、无线能源、电路板并行映射。一个仓室替代维护仓 + 能源仓 + 并行设置。

## 三重能力

### 1. 维护绕过

- 所有多方块机器**永远无维护问题**（Mixin 全局注入 `shouldCheckMaintenance()` 返回 false）
- 无需再手动扳手修理，机器永远保持最佳效率
- 全局生效，只要本 mod 安装即启用，与是否放置仓室无关

### 2. 无线能源

- 放置时**绑定放置者 UUID**
- 定期从全球无线电网拉取 EU 到本地存储
- 需提前通过其他方式（无线输出仓、发电机等）向无线电网注入 EU
- 多方块机器可直接从本仓室取电工作

### 3. 电路板并行映射

- 插入 GT 电路板设置并行数
- 公式：`并行数 = 4^level`
  - LV 电路板 = 4 并行
  - MV 电路板 = 16 并行
  - HV 电路板 = 64 并行
  - EV 电路板 = 256 并行
  - IV 电路板 = 1024 并行
  - LuV 电路板 = 4096 并行
  - ZPM 电路板 = 16384 并行
  - UV 电路板 = 65536 并行

## 使用方法

1. 合成万能维护仓
2. 放入多方块结构的**维护槽位**（原维护仓的位置）
3. 如需无线供电，确保无线电网中有 EU 且放置者已绑定
4. 如需设置并行，在仓室 GUI 中插入对应等级的 GT 电路板

## 合成

铁锭 ×4 + 玻璃 ×2 + 红石 ×2 + LV 电路板（3×3 配方，见配方标签）。

## 注意

- 维护绕过是全局 Mixin，安装本 mod 后所有多方块均免维护
- 无线能源需要配合无线输出仓使用，单独放置无法发电
- 并行数受机器本身最大并行限制，超出部分无效
- 仓室本身需要 EU 才能工作，无线电网无电时机器会停机

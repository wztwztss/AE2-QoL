# 智能倍增（Smart Doubling）

解决 GT 流水线的"逐轮补料等待"：勾选后，合成 CPU 把挂在机器上的样板**一次性推送 N 轮**材料，机器连续加工 N 轮再回来补料。

## 开启方式

以下机器的 GUI 内会出现**智能倍增开关按钮**（悬停有说明）：

- **ME 接口**（方块/线缆面板）：GUI 左侧循环箭头按钮
- **GT 样板输入机**（样板输入总成）：GUI 左下角开关
- **PH 双口输入仓**：GUI 内开关

按介质独立开关，默认关闭。

## 工作原理

1. 下单后 CPU 常规调度到已开启倍增的介质。
2. CPU 计算单次可推送的轮数 N（受原料存量、网络电量、机器缓冲容量、配置上限四重钳制）。
3. 一次提取 `N × 配方材料` 推给机器；产出与功率按 N 轮记账。
4. 大订单每 tick 持续推送直至完成——1T 级订单也不会卡顿。

## 配置

`config/ae2_qof/settings.json` 的 `smart_doubling_max_rounds`：

| 值 | 含义 |
|---|---|
| `0`（默认） | 不限：一次推送尽可能多的轮数 |
| `> 0` | 单次推送轮数上限 |

## 注意

- 合成类（craftable）样板不支持倍增（逐槽一格语义）
- 阻塞模式 / 智能阻塞模式下自动回退逐轮，不会绕过阻塞检查
- 流体接口与假合成模式不倍增

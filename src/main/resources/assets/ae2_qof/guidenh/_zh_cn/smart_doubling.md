# 智能倍增（Smart Doubling）

解决 GT 流水线的"逐轮补料等待"：勾选后，合成 CPU 把挂在机器上的样板**一次性推送 N 轮**材料，机器连续加工 N 轮再回来补料。

## 开启方式

以下机器的 GUI 内会出现**智能倍增开关按钮**（悬停有说明）：

- **ME 接口**（方块/线缆面板）：GUI 左侧循环箭头按钮
- **GT 样板输入机**（样板输入总成）：GUI 左下角开关
- **PH 双口输入仓**：GUI 内开关

按介质独立开关，默认关闭。

## 工作原理

1. 下单后 CPU 常规调度到已开启倍增的介质。
2. CPU 计算单次可推送的轮数 N（受原料存量、网络电量、机器缓冲容量、配置上限四重钳制）。
3. 一次提取 `N × 配方材料` 推给机器；产出与功率按 N 轮记账。
4. 大订单每 tick 持续推送直至完成——1T 级订单也不会卡顿。

## 配置

`config/ae2_qof/settings.json`：

| 键 | 值 | 含义 |
|---|---|---|
| `smart_doubling_max_rounds` | `0`（默认） | 不限：一次发配尽可能多的轮数 |
| | `> 0` | 一次发配的总轮数上限 |
| `smart_doubling_push_cap` | `4096`（默认） | **单次（每 tick）推送轮数上限**：每 tick 最多推这么多轮，剩余轮数下一 tick 继续 |

> 想让每批更大：把 `smart_doubling_push_cap` 调大即可（`smart_doubling_max_rounds` 保持 0）。
> 上限之所以默认 4096，是因为 AE2 的功率探测是"凑够即停"的遍历——一次索要上亿点电量会强制走遍全部储能设备；
> 而且一次性把海量物品塞进机器缓冲会把客户端物品更新淹没（历史上 1T 级订单就是这么卡死的）。
> 服务器算力充裕时可调大，代价是每 tick 的提取量与物品更新量线性上升。

## 注意

- 合成类（craftable）样板不支持倍增（逐槽一格语义）
- 阻塞模式 / 智能阻塞模式下自动回退逐轮，不会绕过阻塞检查
- 流体接口与假合成模式不倍增

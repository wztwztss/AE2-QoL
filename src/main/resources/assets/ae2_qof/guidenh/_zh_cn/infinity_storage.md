# 无限存储元件（功能 16）

对 AE2 的近乎无限容量存储元件：**物品、流体、源质**三通道随意存取，容量与类型数不设上限。

## 用法

1. 合成/获得「无限存储元件」（原 AE2 Infinity Cell，已并入本模组）。
2. 放入 ME 驱动器或 ME 存储箱即可使用。
3. 内容保存在**世界存档**中（元件本体只存一个 UUID 引用）；复制出的元件共享同一份库存。

## 悬停统计

背包中悬停元件即显示实时统计：总计 / 物品 / 流体 / 源质逐行明细，每行附字节估算。

- 默认字母单位（如 `12.34M`）；**按住 Ctrl** 切换科学计数法（如 `1.85×10^25`）
- 数据由服务端实时汇总（内容存世界存档，客户端自动请求）

## NEI 查看

NEI 中对元件按 `U` 打开 **Infinity Cell View** 分页浏览全部内容（物品/流体/源质分页）。

## 说明

- 与独立版 AE2 Infinity Cell 模组**互斥**：安装本模组前需移除原 jar；旧磁盘与数据零迁移兼容
- AppEU 能量通道未包含

# 库存统计终端

集中查看和修改 AE2 标准发信器（Level Emitter）与本模组库存检测覆盖板的免电信息终端。无需逐个跑到机器前调整阈值，在终端前即可统一管理。

## 界面结构（3.31.0 起为左侧竖排双页）

- **左侧竖排页签**分两页：**发信器** / **覆盖板**；页面选择会**记住**（存在终端自身 NBT 里，重开界面、重登后仍停在上次那一页）
- 顶部一行：终端标题、连接状态、以及【连接AE】/【切换网络】按钮（两页共用）
- 每行包含：**目标图标**（物品图标 / **真流体贴图**）、名称、右侧数值（类型·模式·阈值）、以及【高亮】【传送】
- 行高 24px，一屏可见 8 行，超出可滚动

> 目标名称由**客户端**解析，所以在专用服务器上也显示中文（与 AE2 自己的界面同一条链路）。

## 核心功能

### 1. 发信器集中管理（发信器页）

- 自动枚举当前 AE2 网络中所有标准发信器（`PartLevelEmitter`）
- 显示每个发信器的监控目标（含物品图标）、类型（物品/能量）、阈值
- 点击行内名称或数值弹出编辑面板，直接修改阈值
- 修改需 AE2 网络 BUILD 权限
- 能量型发信器：编辑面板上有一行黄字提示（本模组不做额外限制）

### 2. 覆盖板集中管理（覆盖板页）

- 自动发现**本终端所连网络**下所有已安装的库存检测覆盖板（全局注册表，跨维度）
- 显示每个覆盖板的监控目标（物品图标 / 真流体贴图）、阈值、模式（低于开机/高于开机）、在线状态
- 点击条目弹出编辑面板，修改阈值和模式；**改的就是该行显示的那个检测槽位**
- 覆盖板拆卸后自动从列表移除；区块未加载时标记为离线（灰字 [OFF]，图标留空）
- 本网络之外还有覆盖板时，列表为空会提示"另有 N 个属于其他网络，已隐藏"

### 3. 行内动作：高亮 / 传送

- 【高亮】：目标与你在同一维度时画出 10 秒高亮框（覆盖板蓝、发信器紫）；跨维度会提示而不是画一个看不见的框
- 【传送】：传送到目标附近，自动寻找可站立落点（找不到会取消并提示），支持跨维度
- 两者都要通过**会话校验 + 该 AE 网络的 BUILD 权限**（客户端只发坐标，服务端重新解析目标后执行）

### 4. 双模式连网

- **Nexus 无线**：点击"连接 AE"按钮，弹出 Nexus 原生无线网络选择面板，绑定到任意无线网络（和覆盖板完全相同的操作方式）
- **邻接直连**：未绑定无线网络时，自动通过邻接的 AE2 线缆/机器枚举发信器
- 不占用无线频道（`getRequestedChannels()=0`）

## 使用方法

1. 合成库存统计终端
2. 放置在基地任意位置（免电，无需能量）
3. 如需管理无线网络中的发信器，右键打开 GUI，点击"连接 AE"按钮，选择无线网络绑定
4. 如只需邻接网络的发信器，把终端放在 AE2 线缆旁边即可
5. 用左侧页签在【发信器】和【覆盖板】之间切换
6. 点击任意条目弹出编辑面板，修改阈值/模式后自动写回

## 合成

铁锭 ×4 + 玻璃板 ×2 + 红石 ×2 + 基础电路（3×3 配方）。

## 注意

- 终端本身免电，不消耗任何能量
- 发信器枚举需要终端连接到 AE2 网络（无线或邻接）
- 覆盖板列表直接读全局注册表、不需要 AE 连接；但会按终端所绑定的网络过滤
- 修改覆盖板配置后，覆盖板会在下一个检测周期（10 tick）生效
- **从旧版本升级**：老存档里已注册的覆盖板在**所在区块加载后**会自动补全"目标本体"，随后显示中文名与图标；在此之前沿用旧记录（可能是英文名、无图标），不会崩也不会丢数据
- 终端不占用无线频道，仅用于网络选择和绑定

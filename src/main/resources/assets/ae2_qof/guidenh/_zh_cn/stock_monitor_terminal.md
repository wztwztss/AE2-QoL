# 库存统计终端

集中查看和修改 AE2 标准发信器（Level Emitter）与本模组库存检测覆盖板的免电信息终端。无需逐个跑到机器前调整阈值，在终端前即可统一管理。

## 核心功能

### 1. 发信器集中管理

- 自动枚举当前 AE2 网络中所有标准发信器（`PartLevelEmitter`）
- 显示每个发信器的监控目标、阈值、类型（物品/流体/能量）
- 点击条目弹出编辑面板，直接修改阈值
- 能量类型发信器只读（AE2 原生限制）
- 修改需 AE2 网络 BUILD 权限

### 2. 覆盖板集中管理

- 自动发现所有已安装的库存检测覆盖板（全局注册表，跨维度）
- 显示每个覆盖板的监控目标、阈值、模式（低于开机/高于开机）、在线状态
- 点击条目弹出编辑面板，直接修改阈值和模式
- 覆盖板拆卸后自动从列表移除
- 区块未加载时标记为离线（灰色）

### 3. 双模式连网

- **Nexus 无线**：点击"连接 AE"按钮，弹出 Nexus 原生无线网络选择面板，绑定到任意无线网络（和覆盖板完全相同的操作方式）
- **邻接直连**：未绑定无线网络时，自动通过邻接的 AE2 线缆/机器枚举发信器
- 不占用无线频道（`getRequestedChannels()=0`）

## 使用方法

1. 合成库存统计终端
2. 放置在基地任意位置（免电，无需能量）
3. 如需管理无线网络中的发信器，右键打开 GUI，点击"连接 AE"按钮，选择无线网络绑定
4. 如只需邻接网络的发信器，把终端放在 AE2 线缆旁边即可
5. GUI 上半部分显示发信器列表，下半部分显示覆盖板列表
6. 点击任意条目弹出编辑面板，修改阈值/模式后自动写回

## 合成

铁锭 ×4 + 玻璃板 ×2 + 红石 ×2 + 基础电路（3×3 配方）。

## 注意

- 终端本身免电，不消耗任何能量
- 发信器枚举需要终端连接到 AE2 网络（无线或邻接）
- 覆盖板列表不依赖网络连接，通过全局注册表直接读取
- 修改覆盖板配置后，覆盖板会在下一个检测周期（10 tick）生效
- 能量类型发信器只读，无法通过终端修改阈值
- 终端不占用无线频道，仅用于网络选择和绑定

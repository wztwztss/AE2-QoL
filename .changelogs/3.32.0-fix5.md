# AE2 QoL 3.32.0-fix5

对比基准：上一个可用 jar 为 **3.28.0**（v3.18.0 之后本仓库未再打版本 tag，以下为 3.28.0 → 3.32.0-fix5 的全部更新）。

## 新功能

### 3.29.0 · GTNL 蒸汽楼梯模块调速（首批 5 个模块）
- 对 GT-Not-Leisure「蒸汽楼梯」（Steam Elevator，MTE 21155）的蒸汽矿处 / 蜂箱 / 温室 / 蜜蜂育种 / 抽油 I·II·III 提供可配置调速。
- 单份配方时长压到 **1 tick**，一次操作合并 **128 份**（每 6.4 s 一次操作）。
- **蒸汽/t 与改前完全相同**（批处理不放大 EUt，对齐 GT 语义）。
- 输入不足**自动降级**（能供几份跑几份）；**抗卡顿闸门**（凑不够 8 份就保持上游行为，避免退化成每 tick 一次配方检查）。
- 相对改前吞吐：矿处 ×(20~640)×并行、蜂箱 ×6000、育种 ×12000、温室 ×100、抽油 ×1200/600/400。

### 3.30.0 · 每 tick 并行份数 P 旋钮
- 新增 `moduleMaxParallel`（全局，默认 1）与 `oilDrillMaxParallel`（抽油专用，默认 8，0=跟随全局）。
- 并行让每 tick 处理 P 份 ⇒ 每秒产出 ×P（抽油 III：P=1 约 80,000 L/s → P=8 约 640,000 L/s），**蒸汽不变**。
- 时长与配方检查频率不受 P 影响（不增加卡顿）；材料严格按 P 倍扣。

### 3.31.0 · 库存统计终端重做
- 专用服上显示中文目标名（客户端本地化解析）、真实目标图标、左侧竖排双页签。

### 3.32.0 · 自适应电网终端重做
- 子仓列表改为**按主机聚合**（一台主机一行，显示主机名/图标/实时耗电/仓数/额定与实测）。
- 四仓检测改**按类判定**（不再鸭子类型误判），兼容 TecTech 激光源/靶仓。

### 3.32.0-fix5 · 屠宰场模块加入调速
- **蒸汽屠宰场模块（气动刷怪笼）**加入同一套调速：专用键 `entityCrusherMaxParallel`（默认 8）。
- 刷怪笼是 0 数量输入（不消耗）⇒ 并行无需材料、纯倍率。
- 机器自身批处理开启时本模组自动放行（防双重叠加）。

## 修复
- **3.30.0-fix1**：配置文件缺少新增键时自动补写（值保持原样）。
- **3.30.0-fix2**：抽油默认并行 64 → 8。
- **3.32.0-fix1**：槽位安培数按"额定"读取，手改档位不再被周期覆盖。
- **3.32.0-fix2**：修复 fix1 的回归（GT/TecTech 能源仓放不进槽位）。
- **3.32.0-fix3**：停机不再显示巨额耗电（改实测流量）；修背包遮挡 UI。
- **3.32.0-fix4**：实测流量换算成真正的 EU/t（修"实测是额定的 4 倍"）。

## 基础设施
- 全仓 `spotlessApply`（195+ 文件积累的格式违规清零，CI 的 spotless 检查首次转绿）。
- CI：`client-only`（CI 运行时类路径没有 gregtech，runServer 冒烟测试对本模组必然失败，故跳过）。
- CI：release 工作流补 `contents: write` 权限（此前无法创建 Release）。
- 本地 GTNL 编译 jar 改名去掉 `-pre` token（通过 CI 的"无 prerelease 依赖"检查）。

# 4.1.0-fix2 — 产线页点按钮被踢出 GUI 的修复（hotfix 2）

上一个版本：`4.1.0-fix1`。

## 修复

### 产线页三个按钮（新建/导入/预置）一点就退出（P0 级回归 2）
**现象**：产线页顶栏或行内任何按钮一点，整个终端 GUI 被踢出。

**根因**（实例日志实证）：
`IllegalStateException: Widgets created by DynamicSyncHandler can't have implicitly registered sync handlers. All sync handlers must be registered with a variant of 'PanelSyncManager#getOrCreateSyncHandler(...)'`。

MUI2 2.3.88 规矩：DynamicSync 系列组件的 widget 子树里，所有 sync handler **必须**经 `getOrCreateSyncHandler(唯一键, …)` 编号注册（1/2 页签的 `buildActionRow` 证人模式）；产线页把十几个 `InteractionSyncHandler` 直接 `.syncHandler(new …)`（隐式注册）→ 服务端 C2S 处理时构建面板抛异常 → channel 报 critical → GUI 关闭。

**修法**：新增 `serverClick(syncManager, "唯一键", action)` 工具（内部走 `getOrCreateSyncHandler`），产线页 **15 个**交互点全部改造——主页面 3 按钮 + 产线行选择/设置 + 步骤行开面板/候选/删除 + 步骤小面板暂停/写卡/关闭 + 线面板暂停/删除/关闭 + 候选面板行绑定/解绑（键含机器坐标）+ 预置面板行创建（键含 preset 名）+ 导入面板运行 + 5 个关闭按钮。

**同批**：预置行按钮回调改用 `presetName` 变量（原 `name` 引用残留会导致编译歧义）。

## 版本注记

- `4.1.0` 首个包与 `4.1.0-fix1` 都含此回归（fix1 只修了"打不开"，没修"点按钮被踢"）——**请直接跳过前两个包，装本版**。

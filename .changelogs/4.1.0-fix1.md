# 4.1.0-fix1 — 库存统计终端右键打不开的修复（hotfix）

上一个版本：`4.1.0`。

## 修复

### 产线页引入的「终端右键打不开」（P0 级回归）
**现象**：进游戏后对库存统计终端右键，GUI 打不开（原 1/2 页签也一起打不开）。

**根因**（实例日志实证）：
`StockMonitorTerminal.buildUI FAILED: NullPointerException: Cannot invoke "ModularContainer.getPlayer()" because "this.container" is null`。

产线页在 **buildUI 阶段**就调用了 `PANEL_CACHE.computeIfAbsent(syncManager.getPlayer(), …)`（5 个子面板的懒建缓存），而 MUI2 的 `container` 在 buildUI 时尚未建立 → build 抛 NPE → `buildUI` 返回 null → 什么都不打开。

**修法**：面板句柄改为在 `buildPage` 里**同步创建**（`syncManager.syncedPanel(...)`，与 1/2 页签的 `cover_edit/net_select` 同款证人模式）；`syncManager.getPlayer()` 从 buildUI 路径彻底移除，只保留在面板打开时执行的 builder lambda / 点击回调内（那时 container 必已存在）。附带从 HEAD 恢复被误删的 `buildPresetsPanel/buildPresetList`。

**同批**：CHANGELOG 顶部"当前版本"过日期（3.32.0-fix4 → 4.1.0-fix1，审查报告 P1-5）。

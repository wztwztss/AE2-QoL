# 4.1.0 — 产线管理器（第 1 期）

上一个版本：`3.35.0-fix23`。本版为**功能版本**（modVersion 直升 4.1.0）。核心入口：库存统计终端（32107，免电）新增第三页签「**产线**」。

## 新功能

### 产线管理器第 1 期（终端新页签）
- **預置产线一键建线**：产线页【预置产线】→ 点名称即建线。首批 7 条 huijiwiki RecipeCalculator 模板：**硅岩 / 独居石主线 / 氟碳镧铈主线 / 钐精粉主线 / 海晶酸线 / 湿件线 / 异氙线**；建线后仍可 NEI 导入或编辑器修改。
- **步骤级真停机**：【暂停/恢复】直接写 GT 机器停机位（`disableWorking`/`enableWorking`）；整线级入口在【设置】里。删除产线/解绑机器时自动恢复机器可工作。
- **两种绑定方式**：候选面板点选（团队声明区块内已加载的 GT 多方块；一台机器只属一条产线）+ **新物品「产线绑定卡」**（终端里写卡 → 对机器 Shift+右键；生存配方 4 纸 + 1 铁锭，挂主创造页）。
- **汇总面板**（BigInteger 跨重启持久）：外部输入/末端产物分物品展示累计与约速率；wiki `start[]` 期望边界持久显示。
- **高亮【传送】**：绑定过机器的步骤行尾复用库存统计终端的传送/高亮（会话 + AE BUILD 服务端校验）。
- **语言/权限**：每团队 16 条产线、64 步上限；除算所有聊天提示/徽标/tooltip 中 σχέ 정（en_US 全量翻译）；GuideNH 玩家指南新增「产 line Manager」双语页（index 计数 21→24）。

### wiki JSON 导入（產线页内）
- 粘贴 huijiwiki RecipeCalculator 的模板 JSON（**可带模板外皮与注释**，自动剥壳），支持 `recipeQuery[].{input,output,type,branch/branches,hierarchy}`、`start` 数组/旧 map/token 三形态、`env`、`prime`、`config`；`groups`/`presets` 不参与建线。
- 未解析名**不静默丢弃**，逐条列错；总量 ≤28KB（更大建议预置/拆分）。

## 修复（同批次自审发现的缺陷）

- **绑定卡材质缺失**：`proline_card.png` 之前不存在，游戏内显示紫黑棋盘 → 已补 16×16 材质。
- **lang 缺陷真修**：`ae2_qof.wireless.bind.success` 同键双值导致带 `%s` 格式的绑定提示被后置值覆盖（信道号不显示）→ 拆分键 `ae2_qof.wireless.bind.network.success`；`ae2_qof.threads.tab.threads` zh 缺失已补。
- **产线导入器**：`start` 被 `steps` 顶掉的逻辑 bug；旧 map 与 token 形态支持；未解析项不再产生空步骤。
- **泄漏清理**：产线 UI 关闭时清空每玩家临时表；采样退避/连败 Map 按“非活跃产线”GC。
- **静默 catch → warnOnce**：锚定终端/绑定机器的 TE 读取失败有日志（其余守卫均有三态日志或用户可见 fallback）。

## 一、核心结论（先看这条）

**GT 的图标注册（`registerIcon`）对本 mod 自定义的新路径恒返回 missingno 占位贴图。**

图集在**启动期**构建完成，只扫描 GT 源码里**写死引用**的贴图路径。
任何**运行时新造的路径**（无论什么命名空间、什么注册时机）都不在扫描范围内。

**唯一可用的机制 = 复用 GT 已有路径 + 资源包同名覆盖**（Modernity-GTNH 的做法）。

> **2026-09-19 更新：上面“唯一可用”只对“无Mixin介入的普通注册”成立。**
> 用户已选定方案 B，并且 fix45 已实现新结论：
> 在原版方块图集的 `registerIcons()` 尾部，用 Mixin 把 25 张 v7 路径补进注册列表，
> 再由本帧图集装订流程处理，资源包即可正常解析自有路径；
> 渲染端不再依赖旧 stitch 事件，而是直接读取 Mixin 回填的图集图标。
> 本结论把“直接 registerIcon 拿 missingno”和“registerIcons 阶段补注册”区分开。

## 三、决定性证据链（怎么确认的）

### 3.1 UV 完全相同 = missingno

25 张**不同**贴图，注册后拿到的 UV **完全相同**：

```
getIcon STITCHED .../universal_maintenance_hatch/FRONT UV=[0.17187744,0.5273462]-[0.1757788,0.53124756]
getIcon STITCHED .../adaptive_net_terminal/FRONT     UV=[0.17187744,0.5273462]-[0.1757788,0.53124756]
getIcon STITCHED .../wireless_energy_input/FRONT     UV=[0.17187744,0.5273462]-[0.1757788,0.53124756]
```

- UV 宽度 `0.1757788 - 0.17187744 = 0.0039013` ≈ **1/256.32**
- 换算：`0.0039013 × 4096 = 15.98 px` ≈ **16px**
- 即：25 张图全指向图集里**同一个 16×16 格子** = missingno 占位符

### 3.2 missingno 的伪装（前 4 轮被它骗了）

missingno 占位 sprite **恰好"看起来正常"**：

| 表象 | 真相 |
|---|---|
| `getIcon()` 返回**非 null** | 拿到的是 missingno，不是 null |
| `getIconName()` 返回**正确路径** | 注册名被回填到 name 字段 |
| `getIconWidth/Height` = **16×16** | missingno 本身就是 16×16 |

→ 所以前几轮"注册成功、图标正常"的判断**全部是被 missingno 误导的**。

### 3.3 与 Modernity 的对比（关键破案点）

| | Modernity-GTNH（正常显示） | 本 mod 的 8 轮尝试 |
|---|---|---|
| 贴图位置 | `assets/gregtech/textures/blocks/basicmachines/<机器>/OVERLAY_*.png` | `ae2_qof:...` / `gregtech:blocks/ae2qol/...` |
| 做什么 | **同名覆盖** GT 已引用的路径 | **注册**全新路径 |
| 要注册吗 | **不要** | 要 → 恒 missingno |

**已用实测数据排除的干扰项：**
- ❌ 不是"图太多"：Modernity 有 **4433 张** PNG，每机器 **34 张**
- ❌ 不是"一张图含六面"：它同样每面独立 16×16
- ❌ 不是色彩格式：它含 **932 张** RGBA 真彩（ct6）16×16，同样正常

## 四、GT 侧的硬约束（已查证）

### 4.1 没有为附属 mod 预留的空槽位

`javap gregtech.api.enums.Textures$BlockIcons` 统计：

- `IIconContainer` 字段总数：**1845**
- `OVERLAY_*`：**921** 个 —— 全部有主
- `CASING*`：**206** 个 —— 全部有主
- `DEFAULT` / `UNUSED` / `PLACEHOLDER` 类字段：**0 个**

→ **覆盖任何 GT 已有路径，都会连带改掉使用该路径的 GT 机器外观。**

### 4.2 覆层不支持分面

GT 自己的写法（反编译 `MTEHatchMaintenance`）：

```java
TextureFactory.builder()
    .addIcon(Textures.BlockIcons.OVERLAY_AUTOMAINTENANCE)
    .extFacing()      // 负责覆层的朝向/面位分配
    .build()
```

`ITextureBuilder` 全部方法：`build()` / `addIcon(IIconContainer)` / `setRGBA(short[])` /
`stdOrient()` / `extFacing()` / `glow()`

**`OVERLAY_*` 是整体贴附**，由 `extFacing()` 决定朝向；
**不存在"这个覆层只管正面"的概念** → v7 的 FRONT/TOP/SIDE 三张设计无法分别呈现。

## 六、方案 B 实施档案（fix45，当前方案）

### 6.1 用户决策

用户已明确选择 **方案 B**；材质只保留分面机制，不再把 R2 覆层推到 8 台。
万能维护仓也回归与其他 7 台一致的分面实现，避免覆盖 GT 共用覆层。

### 6.2 实现方式

- `MixinTextureMap` 注入原版方块图集的 `registerIcons()` / `func_110573_f()` 尾部；
- 只在 `textureType == 0` 的方块图集生效；
- 用 `registerIcon()` / `func_94245_a()` 补注册 25 张 v7 路径；
- 注册得到的图集图标写入 `ModTextures.registerBaked(...)`；
- 机器渲染优先读 `BAKED` 图标，读不到才回退 GT 机箱；
- 旧 `TextureStitchEvent.Pre` 通道不再使用，只保留兼容；
- 反射解析 MCP/SRG 两套成员名，避免生产环境静默挂空。

请使用完整包 `AE2QoL-v7-resourcepack.zip`，路径：
`assets/gregtech/textures/blocks/ae2qol/<machine>/{FRONT,TOP,SIDE}.png`
以及 `assets/gregtech/textures/blocks/ae2qol/_shared/BOTTOM.png`。

旧 `AE2QoL-v7-overlay-test.zip` 只含维护仓覆层，不再参与方案 B；可删可留，但不再是判断依据。

## 七、下一步实测（fix45）

### 7.0 fix46 修正：透明 / 空贴图的根因（先看这条）

fix45 部署后装完整资源包出现**机器透视（透明）**。日志证据：

```
[AE2QoL-TEX] getIcon HIT gregtech:blocks/ae2qol/universal_maintenance_hatch/TOP UV=[0.0,0.0]-[0.0,0.0]
```

UV 全 0 = sprite 尺寸 0×0 = **从未被装订进图集**。资源包本身没问题（25 张 PNG 均为
16×16 全不透明、路径正确）。

**根因**：`MixinTextureMap` 用了「只注册一次」的静态开关，但
`TextureMap.registerIcons()` 每次执行都会先 `mapRegisteredSprites.clear()`，
而方块图集在启动期会多次执行 `registerIcons()`（构造器 → 首次 `loadTextureAtlas`
（`skipFirst` 跳过装载）→ 每次 `refreshResources()`）。只注册一次，就会让**真正装载的
那一轮**清单里没有这 25 条，sprite 永远停在 0×0。

**fix46 修复**：

- 删除「只注册一次」开关，每次 `registerIcons()` 都补注册（与其 clear/重建语义对齐）。
- `ModTextures` 增加退化 UV 检测：`getMaxU()/getMaxV()` 全 0 时回退 GT 机箱，
  不再把空 sprite 交给渲染器。
- 兜底图标改为多级安全取值，永不为 null（null icon 会触发 `Already tesselating!` 崩溃）。

**关键结论**：只要 sprite 的 UV 出现 `[0.0,0.0]-[0.0,0.0]`，就是「没进图集」，
与资源包内容无关，先查注册时机/次数。

1. 只部署 `AE2-QoL-3.19.0-fix45.jar`，不要与旧版共存；
2. 把完整资源包拖到资源包列表顶部；
3. 先用默认 `v7_textures=auto` 进世界看 8 台；
4. 再把 `v7_textures=off` 重启，确认强制回退；
5. 最后用 `v7_textures=on` 重启，确认强制开启；
6. 收集日志中的 `[AE2QoL-TEX] getIcon HIT`：UV 互不相同为正常，完全相同为 missingno。

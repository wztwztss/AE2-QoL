# 产线管理器 玩家完整使用流程（4.1.0）

> 版本基线：AE2-QoL `4.1.0`（见 `gradle.properties:modVersion`）/ GTNH 2.9.0-beta-3 / MC 1.7.10。
> 本页是玩家向使用指南；实现细节与自审结论见 `docs/PRODUCTION_LINE_MANAGER_SELF_AUDIT.md`。

## 一、安装与前置

1. 从 `build/libs/AE2-QoL-4.1.0.jar` 拿产物（或 Release 里的同版本 jar），客户端与**服务端**都要装（本 mod 是双端 mod）。
2. 前置依赖（整合包自带）：AE2、NotEnoughItems、CodeChickenLib、AE2FluidCraft、GregTech、StructureLib、modularui2、ServerUtilities；本 mod 内建 `libs/ServerUtilities-2.4.9.jar` 仅用于编译，请确认**运行时** ServerUtilities 已装。
3. **产线功能 = 团队功能**：必须在一个 ServerUtilities 团队里才能新建产线（无团队时新建会被拒绝，提示先建团队）。
4. AE2 侧准备：库存统计终端（`gregtech:gt.blockmachines:32107`）放在产线机房，右键它打开后 → 第 3 个页签「产线」就是本功能入口。

## 二、快速开始（最短路径）

1. **建一条产线**：产线页顶栏 → [+新建产线]。默认名会带时间后缀，可在「设置」里改名。
2. **选一条产线**：在产线列表里**点产线行**（选中会有绿色边框；后续操作针对这条线）。
3. **装一台机器**：该条线下方的步骤区 → 点步骤行的数值区 → 弹出「候选机器」面板 → 从团队声明区块里**已加载**的 GT 多方块机器里挑一台点击绑定。
   - 跨产线绑定同一台机器会被提示并拒绝（一台机器只属于一条产线）。
4. **看状态**：步骤行实时显示 `在产 n/绑定 m` 与徽标（空闲/部分在产/在产/已暂停）。
5. **暂停/恢复**（**真停机**，直接停机位写入机器）：
   - 步骤级：点步骤行名称 → 步骤小面板 → 【暂停/恢复步骤】；
   - 整线级：产线行尾【设置】→【暂停/恢复整线】。
   - 线被删除或机器被解绑，会**自动把机器恢复为可工作**，无需手动干预。
6. **汇总面板**：页面底部展示每条外购物料/末端产物的累计量（重启不丢）与约速率（约 10 秒一次刷新）。

## 三、预置产线（推荐用法）

产线页顶栏 → 【**预置产线**】→ 面板列出已打包的 huijiwiki 产线模板 → **点击名称即建线**，内容来自 huijiwiki RecipeCalculator。

当前内置（4.1.0 首批）：
| 名称 | 内容 |
|---|---|
| 硅岩 | 氟锑酸路线 + 硅岩/富集/超能三套主分支 |
| 独居石主线 | 独居石 → 富铈/钐精粉双分支 → 铪锆/二氧化铈/铕钐钆/小分支 |
| 氟碳镧铈主线 | 氟碳镧铈 → 铈/钐/钕镧分支 |
| 钐精粉主线 | 钐精粉 → 四种处理模式切换 |
| 海晶酸线 | 海晶碎片 + 过氧化氢增殖循环 → 海晶体/海晶酸 |
| 湿件线 | 培养皿产线（4 组分支选择） |
| 异氙线 | 异氙 → 拉多 X 聚合物 |

建线后即可按 「二、快速开始」++++ 绑定机器。中文名→注册键自动解析在 **4.2.0** 完成；目前预置线的 AE 存量/累计列对**部分**产品是对的，对未解析项会在导入/创建报告里列出（不丢弃，仅提示）。

## 四、进阶用法

### 1. wiki 粘贴导入（替代预置）
顶栏【wiki 导入】→ 粘贴 huijiwiki RecipeCalculator 的 JSON（带上模板外皮也行，解析器自动剥壳）→ 【解析并创建】。上限 28KB（更大请预置/拆分）。
导入器支持的 JSON：`recipeQuery[].{name,input,output,type,branch/branches,hierarchy}`、`start`（数组或旧对象）、`env` 数组、`prime`、`config`。`groups`/`presets` 会被忽略（不参与建线，只做参考）。

### 2. NEI 一键转样板（非产线域）
NEI 里右键任意配方 → 智能通配样板 → 上传等功能在 AE2-QoL 2.x 已有。

### 3. 产线绑定卡（对**非面板**方式绑定）
1. 产线页里**选中产线 + 选中步骤**（点名称行）；
2. 手持 **产线绑定卡**（物品名：产线绑定卡）→ 【写入手持绑定卡】；
3. 手持该卡对准要绑定的 GT 多方块机器 `Shift+右键` → 成功回复；失败原因会在聊天提示。
> 绑定卡可以重复写入不同的「产线,步骤」组合，每次写入都会覆盖。

### 4. 高亮 / 传送
绑定过机器的步骤行尾出现【高亮】【传送】按钮，指向**该步骤绑定的第一台机器**。权限 = 走既有 AE2 无线终端的会话+AE BUILD 校验（同库存统计终端）。

### 5. 失效绑定 / 解绑
同一台机器的绑定记录固定存在（记录坐标，不随机器移动）；当区块未加载或机器拆除，显示"离线"。`长时间未询到（≥3 天）` 会标记为新状态；重新绑定或解绑即可清理。

### 6. 每团队 16 条上限
用【设置】→【删除整线】（3 秒内点两次）可释放名额。

## 五、常见问题（FAQ）

- **为什么预置线 AE 存量列是空的？** 预置产线的物品名是中文 wiki 名；4.1.0 还没做中文名→注册键自动解析。可以把步骤行用于绑定/状态监控（不受影响），4.2.0 会解析并补上存量。
- **步骤行上没看到【高亮】【传送】按钮？** 该步骤还没有绑定机器。
- **候选机器面板是空的？** 属你的团队在**已在当前世界加载的**声明区块内，没有任何 GT 多方块机器在线。
- **_【暂停/恢复】没有反应？** 通常是**区块未加载**；进入区块后再试。产线所在区块未加载时，采样的机器状态会跳过（不崩溃）。
- **存档里 AE2QoLProductionLines.dat 是什么？** 产线定义与累计数据，WorldSavedData 存档文件，勿手动删。
- **产线数量/步骤有上限吗？** 每团队 16 条、单产线 64 步。

## 六、维护与排障

- 产线采样失败会连败退避 5 分钟并在日志里 WARN `[AE2QoL] 产线 <id> 连续失败...`；恢复后自动清零。
- 线路守卫：ServerUtilities 未装时**整个产线页禁用**并在日志三条分支各打一条 INFO/ERROR（已启用 / 未检测到 / 失败）。
- 如果 ServerUtilities 改了 modid，产线守卫也会禁用并把原因输出到日志（关键类判据兜底）。
- 语言的硬编码残留（zh 优先显示）见自审报告；en_US 的翻译对全部界面键已补齐。

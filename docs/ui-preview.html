⑤ 操作流程（点击路径）

右键库存统计终端
 └─ 第 3 页「产线」
     ├─【+新建产线】──→ 建空线（锁定当前终端 AE 网络）
     ├─【预置产线】───→ 点名称 ──→ 一键建整线（含分支/层级/start）
     ├─【wiki 导入】──→ 粘贴 JSON ──→ 解析并创建
     ├─【设置】───────→ 重命名 / 暂停整线 / 删除整线(两击)
     ├─ 点产线行 ─────→ 选中该线（下方步骤/汇总切换）
     ├─ 点分支 chip ──→ 过滤步骤视图
     ├─ 点步骤名 ─────→ 步骤小面板：暂停 / 写绑定卡 / 高亮 / 传送
     ├─ 点步骤数值区 ─→ 候选机器面板：点机器=绑定，再点=解绑
     └─ 点步骤 ✕ ─────→ 删除该步骤
状态徽标：● 在产　◐ 部分在产　○ 空闲　⏸ 已暂停（真停机）

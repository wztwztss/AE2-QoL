# AE2 QoL — 更新日志

> 面向使用者的简洁更新日志（按版本）。开发者向详细改动、已知风险登记见项目根目录的 **`CHANGELOG.md`**。

---

### 3.1.0 — 全量安全加固（2026-08-16，作者 wztwzt）
- **修复**：合成完成通知不再因假玩家/非 MP 玩家强转崩溃，长合成期间下线的玩家也不会触发通知 NPE
- **修复**：从 AE 网络提取物品不再丢物——先模拟计算、背包容量预检，放入失败时剩余物品归还网络
- **修复**：样板上传/撤回增加权限校验（仅持有对应安全权限的玩家可操作共享网络中的样板）
- **修复**：全部客户端到服务器网络包归队到服务端线程处理，不再在 IO 线程并发访问网络/容器，消除随机崩溃与状态不一致
- **修复**：NEI 配方页 AE 角标恢复正常（重写注入点适配 NEI 2.8.19）
- **修复**：Provider 列表全量扫描加限流，防恶意连发卡服；IO 端口倍率乘法防溢出
- **修复**：无线收发器动作仅允许操作自己当前打开的界面；合成下单/提取/样板交换全部异常兜底
- **清理**：移除 NEI 书签传输刷屏日志

### 3.0.2 — 流体直接显示（2026-08-15，作者 wztwzt）
- **修复**：桶/单元等流体容器在 NEI 角标和 tooltip 中改为直接显示流体本身的量（mB），不再显示容器个数
- **修复**：纯流体（水/岩浆/氢气等，ae2fc `ItemFluidPacket`）现在通过 damage 值识别流体，在 NEI 角标和 tooltip 中直接显示流体量
- **修复**：桶/单元等容器物品改为显示**容器本身在网络中的数量**（AE 里真的有该容器才显示），不再把容器当流体显示流体总量
- **改进**：流体 tooltip 追加流体本地名（如 `4.5P mB 蒸馏水`）
- **清理**：移除 4 条导致刷屏的流体缓存日志

### 3.0.1 — 崩溃修复 + 数值扩展 + 流体角标 + 合成表（2026-08-15，作者 wztwzt）
- **修复**：服务器上 Shift+左键从 NEI 取 AE 物品时被踢出（包解码越界）——现已完全兜底，任何网络包解码异常都不会再踢人
- **修复**：点击"重新规划"崩溃；合成完成通知与 IO 端口倍率在单机不生效
- **改进**：物品数量格式化支持到 P/E（更大数值）；流体数量在 tooltip/书签/配方角标中显示
- **新增**：本模组全部方块/物品的原版合成配方（强化 IO 端口、无线收发器、无线连接器、无限磁盘）

### 3.0.0 — 无限磁盘 + NEI 配方 AE 角标 + 合成通知 + Replan + 强化 IO 端口（2026-08-14，作者 wztwzt）
- 新增无限水岩浆磁盘（含合成配方）
- 新增 NEI 配方页 AE 叠加角标（编码样板图标 + 数量）

- 新增强化版 IO 端口（传输倍率 256 倍）
- 新增 NEI 物品悬浮显示 AE 存量/可合成

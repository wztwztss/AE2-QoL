### 3.8.1 — 修复专用服务器二合一终端踢人崩溃（2026-08-24，作者 wztwzt）
- **修复**：专用服务器上使用二合一终端的「转移合成表（NEI 填充）」「切换合成/处理模式」「上传装配矩阵」时被踢出服务器（`Undefined message for discriminator 17`）
- **原因**：部分网络包处理器引用了仅客户端存在的类，在专用服务器上注册失败且未中断启动，导致约一半网络包缺失；单机不受影响
- **影响范围**：3.8.0 及更早版本在**专用服务器**上均存在此问题（NEI 上传/取物/下单等正常，具有迷惑性）；单人与局域网联机无影响
- **附带**：聊天栏操作结果提示、滚轮替换候选预览的网络包处理统一归队到客户端主线程，消除潜在并发隐患

### 3.3.5 — 修复智能倍增（GT/PH 样板输入机）实测失效（2026-08-17，作者 wztwzt）
- **修复**：3.3.3 新增的智能倍增在 GT 样板输入机（2714/2715）与 ProgrammableHatches 双口输入仓（22130/22179）上实测「勾选后无效 + 无法发配物品」——功率门槛不足即整体跳过介质导致 CPU 零推送；原料探测严格全量匹配导致 N 静默降为 1
- **修复方案**：改为 GTLCore 式单次推送——原料不足按 SIMULATE 可提取轮数钳制 N、功率不足逐轮下调 N、N=1 走原版路径；PH 走 `pushPatternMulti` 按实际接受轮数记账；异常自动回退原版 executeCrafting，不拖死 CPU
- **兼容**：保持 `@Inject(HEAD)+cancel`，ProgrammableHatches 共存不受影响

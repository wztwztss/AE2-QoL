# 设计稿（暂存·待线框稿敲定）：在保留「内置电路/不消耗物品」的基础上，为每个样板格新增独立的电路槽与催化剂槽

> **状态：暂存（shelved）**：本文只记录需求与设计，**不动代码**。
> 提出：2026-09-27（用户）；口径修订：2026-09-27 晚（用户：「在不删除内置电路的基础上再加上独立的电路槽和不消耗物品槽，按鼠标中键打开」）。
> 触发它的实测：一舱内两张通配样板，**后放进来的会把先前那张的电路覆盖掉** ⇒ 实际等于"一个舱室只能放一张通配样板"。
> 前置条件：主链（识别/下单/合成）已由 3.43.0 修通并验收；本设计按用户 UI 铁则**须先敲定线框稿**再动代码。

## 一、为什么要做（动机与证据）

### 1.1 冲突机制（已定位）
现有实现把"电路"放在**样板**里（样板 NBT 子树 `ae2qolSmartWildcard/Circuit`），索引期由
`SmartWildcardCircuit.apply(...)` 把该号写进**机器唯一的虚拟电路槽**。
⇒ 同一舱室放两张通配样板时，**后索引的那张覆盖前一张的电路值**，两张样板实际上共用了一个电路。
用户实测（2026-09-27）：MK.III 上"第一张样板是 1 号电路、第二张是 2 号电路，后放进去的会覆盖前面的"。

### 1.2 结论
"电路"与"催化剂"本质是**机器某个样板格此刻的工艺参数**，不是"这张样板覆盖哪些配方"的一部分。
把它们做成**按格独立**，冲突自然消失；而现有的"样板自带电路"**保留**（作为兜底与向后兼容），
优先级遵循"**每格设置 > 样板自带 > 整机设置**"（详见 §2.2）。

### 1.3 已有的基础（不用从零做）
本模组**已经**有一个中键手势：`mixin/mui/MixinItemSlotWildcardGesture` 拦 `ItemSlot.onMousePressed`，
对智能通配样板弹出轻量电路选择屏，并由 `SmartWildcardSlotCircuitPacket` 把电路号写回**样板 NBT**。
本设计把它**扩展**为：中键打开**该格的设置面板**（电路 + 催化剂），数据**写到机器**（按格保存），
样板 NBT 那条写回路径保留原样不动。

## 二、目标设计

### 2.1 一句话
> **保留样板自带的电路/不消耗物品；另外给每个样板格加一个"格设置"：该格独立电路 + 该格独立催化剂，
> 用鼠标中键在样板格上打开。**

### 2.2 取值优先级（取用时）
1. **该格独立电路**（新增，机器侧按格保存）→ 命中就用它烧成电路物品随该格输入推进总线；
2. 该格没有设置时 → 沿用**样板自带电路**（现有行为，`state.circuit`）；
3. 样板也没带 → **整机设置**（现有机器自己的电路控件，完全不动）。
催化剂同理：**该格催化剂**优先；否则用样板自带的 `NonConsumed`；都没有就不注入。

### 2.3 涉及的宿主（五处，全部都要有）
| 机器 | MTE / 类 | 备注 |
|---|---|---|
| GT 样板输入总成 | 2714 / 2715 `MTEHatchCraftingInputME` | |
| GTNL 超级样板输入总成 | 21504 / 21505 `SuperCraftingInputHatchME` | 144 格 |
| PH 编程样板输入总成 | 22069 `PatternDualInputHatch` | 原版 36 格 |
| PH MK.II | 22179 | 36 格 |
| 本模组 MK.III | 32108（继承 PH 基类） | 144 格 |
> AE2 ME 接口/样板供应器那条链没有"每格"概念，**不覆盖**，继续沿用样板自带 + 玩家手动。

### 2.4 数据模型（机器侧，按格对齐）
```text
机器 NBT 新键：ae2qolSlotMeta（NBTTagList，按样板槽下标对齐）
  每项：{ Slot:int, Circuit:int(-1=未设置/继承), Catalyst:{ItemStack NBT} }
```
- `Circuit`：`-1` = 未设置（走样板自带 → 整机）；`1..24` = 该格指定；
- `Catalyst`：单个 ItemStack（可空）；
- **按下标对齐**：GTNL 会自动整理、玩家会移动样板 ⇒ 整理/变更后按下标重排，无法对齐时**打 WARN**（不静默错位）；
- 跟随机器 `markDirty()` 持久化；区块重载后保持。

### 2.5 生效方式（关键：怎么"按格"起作用）
取用发生在**该格 push 的那一刻**（GT/GTNL/PH 三族的槽位 `insertItemsAndFluids` 路径）：
1. **电路**：把该格的电路号**烧成一个电路物品**（`gt.integrated_circuit`，damage = 该号），
   随该格输入一起推进输入总线 —— 这正是 GTNH 原生"样板带电路"的机制，机器按这一格的电路匹配配方，
   **不再需要动机器唯一的虚拟电路槽**，因此两张样板互不覆盖；
2. **催化剂**：把该格催化剂物品**一并推进输入总线**，但它**不写进样板的 in 列表** ⇒
   AE 不会去凑它、也不会消耗它（GT 的 notConsumed 配方语义）；催化剂实物保存在该格自己的槽位里，可反复使用；
3. 该格未设置时，行为与现在**完全一致**（回落到样板自带/整机）。

### 2.6 UI（中键打开"该格设置"面板）
现有中键手势直接打开的是"电路选择屏"，本次扩展为"**格设置面板**"：
```text
        ┌── 样板格（N） ──┐
        │  [ 通配样板 ]   │  ← 鼠标中键点这里
        └────────────────┘
                 │ 中键
                 ▼
   ┌──────── 样板格 N 的设置（轻量弹窗，浅底深字、不用 § 颜色码）────────┐
   │  电路： [ 继承 ]  [1] [2] … [24]      ← 点数字即设；"继承"= 走样板自带/整机 │
   │  催化剂： ┌────┐   ← 真实物品槽：可放入/取出、支持 NEI 拖入            │
   │          │ ▢  │                                                      │
   │          └────┘                                                      │
   │  提示：本格设置优先于样板自带与整机设置；留空即沿用下层。                │
   │                                        [ 清除本格设置 ]  [ 关闭 ]      │
   └──────────────────────────────────────────────────────────────────────┘
```
交互约定：
- **只影响被点的那一格**；面板标题明确写出槽位号（如"样板格 3 的设置"）；
- 写入走**一次轻量 C2S 包**（`{x,y,z, slot, circuit|-1, catalystStack|null}`），服务端校验
  BUILD 权限与距离后写机器 NBT + `markDirty()`，失败必须留日志（本仓"不许静默降级"原则）；
- 中键手势的适用范围沿用现有实现（GT / GTNL / PH 家族的 MUI2 `ItemSlot`；AE2 原生 `Slot` 不触发）。

## 三、明确"不做什么"（按用户口径）
| 对象 | 处理 |
|---|---|
| 样板自带的电路（`state.circuit`） | **保留**，不删；作为该格未设置时的中间层 |
| 样板自带的不消耗物品（`NonConsumed`） | **保留**，不删；同上 |
| 整机电路控件 | **保留**，完全不动 |
| `SmartWildcardCircuit`（索引期写机器虚拟电路槽） | **保留**，但**降级为"该格未设置时才写"**（否则仍会互相覆盖）——这一点实施时确认 |
| 现有中键手势 | **保留并扩展**：仍可改样板自带电路；新增"该格设置"面板 |

## 五、验收标准（实施时用）
1. 同一舱室放**两张通配样板**，各自设不同电路（如 1 / 2），**下单后两张都能按各自电路正确合成**（不再互相覆盖）；
2. 每格设置在该格未设置时，行为与今天完全一致（样板自带 → 整机）；
3. 重启/区块重载后每格设置保持；样板被移动/整理后设置不串格（对齐失败有 WARN）；
4. 催化剂：该格放模头/模具后，配方能匹配、**不被消耗**、AE 不会去凑它；
5. 中键手势在五处机器上都能打开"该格设置"，面板只影响被点的那一格；
6. 中英语言键、指南页、README/CHANGELOG/MOD_MAP 同步。

## 五、JSON字段说明

```json
{
  "type": "production_line",          // 固定类型
  "id": "hydrogen",                   // 唯一标识，用于注册和匹配
  "name": "氢产线",                    // 显示名称
  "category": "lv_gas",               // 分类（阶段_类型）
  "description": "...",               // 描述
  "minVoltageTier": 1,                // 最低电压等级（1=LV,2=MV,3=HV,4=EV,5=IV,6=LuV,7=ZPM,8=UV,9=UHV,10=UEV）
  "requiredMachines": [               // 激活解锁所需机器（每步一台）
    { "item": "...", "meta": 0, "count": 1, "note": "..." }
  ],
  "inputs": {
    "items": [ { "item": "...", "meta": 0, "count": 1, "note": "..." } ],
    "fluids": [ { "fluid": "...", "amount": 1000, "note": "..." } ]
  },
  "outputs": {
    "items": [...],
    "fluids": [...]
  },
  "euPerTick": 30,                    // 每tick能耗（取全流程最大值）
  "duration": 2000,                   // 总时长（ticks），0=待计算
  "parallel": 64,                     // 并行数建议
  "_note": "..."                      // 配平说明（非标准字段，供参考）
}
```

## 六、待确认事项汇总

### P0（实施前必须确认）
1. **物品/流体注册名**：所有JSON中`item`/`fluid`字段的`meta`值均为占位符0，需从GTNH `ItemList`/`OreDict`/`FluidRegistry`确认准确值
2. **RecipeMap maxIO上限**：铂处理（输入12种/输出13种）、稀土处理（输入10+种/输出15+种）、下界合金（输出16种）可能超出默认maxIO，需确认或调整
3. **小数物品处理**：B.8铜粉0.111、B.5碳粉0.2/硫粉1.15，JSON不支持小数，需放大配方或用NBT标签

### P1（实施时需处理）
4. **duration计算**：B.5/B.8/B.14/B.16/B.18/B.19/B.22/B.23/B.24的duration为0，需根据各步骤EU/t×时长加权计算
5. **requiredMachines的meta值**：所有多方块机器的meta值为占位符0，需从`ItemList.java`确认准确枚举名和meta
6. **框架版配方**：B.18异氙线、B.19生物线、B.22稀土处理（部分子线）、B.23凯芙拉（子线数量）、B.24高辛烷值汽油（石油数量）的净输入/净输出数量为0或待推导，需完整线性方程配平

### P2（可选优化）
7. **B.4聚乙烯**：当前为乙醇脱水简化路径（MV，2步），wiki推荐LV石油路径（5步），可作为可选配方
8. **B.20晶体系列**：可选精致绿宝石路径（10%概率EV）或菌泥路径（60%概率），概率配方JSON如何处理需确认
9. **B.21 Ce:LuAG**：可选氪/氙路径（产率较低）或真空炉路径（2台机器），当前取气奥路径100%
10. **B.23凯芙拉**：养蜂法可选（UHV复制机基座，非纯GT化工）

## 七、使用说明

1. OpenCode开发时，将本目录所有JSON复制到`config/ae2_qof/production_lines/`（或模组内`resources/assets/ae2_qof/production_lines/`）
2. `ProductionLineRecipeLoader.java`读取JSON并注册为GT RecipeMap配方
3. `_note`字段为配平说明，加载时应忽略（非标准字段）
4. 催化剂识别逻辑：inputs和outputs中相同item+fluid且amount相同的物品/流体自动识别为催化剂（不消耗但必须存在）
5. 放大倍数已在JSON中应用（如铂处理×5、硅岩处理×4），实施时直接使用JSON中的数量即可

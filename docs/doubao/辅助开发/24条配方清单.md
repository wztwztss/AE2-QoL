## 放大倍数说明

部分配方因产率导致非整数物品数量，JSON实施时需整体放大：

| 配方 | 非整数项 | 建议放大倍数 |
|---|---|---|
| pbi | 铜粉0.111 | ×9 |
| platinum | 铑粉1128.6 | ×5 |
| silicon_rock | 氢氧化钠/铟 | ×4 |
| diesel | 硫粉0.604 | ×250 |
| tungsten | 锂/锰/铁/钙粉18.3/10.7 | ×10 |
| netherite | 运行次数含小数 | 无需放大（运行次数不影响物品数量） |
| zinc_thorium | 运行次数含小数 | 无需放大 |
| rare_earth | 钐粉32.7/铈粉0.667 | ×1000（建议） |

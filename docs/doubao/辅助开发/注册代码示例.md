# 产线聚合器注册代码示例

> 供OpenCode直接粘贴使用。所有代码基于项目现有模式（参考CommonProxy.java中AdaptiveNetTerminal的注册方式）。

## 一、CommonProxy.java 注册代码

在 `CommonProxy.java` 的 `init()` 方法中，AdaptiveNetTerminal注册之后添加：

```java
// ===== Production Line Aggregator =====
try {
    productionLineAggregator = new MTEProductionLineAggregator(
        32120,
        "production_line_aggregator",
        "Production Line Aggregator",
        4);  // tier=4(EV)，实际等级由外壳决定，这里只是基础等级
    GameRegistry.addShapedRecipe(
        productionLineAggregator.getStackForm(1L),
        "ccc",
        "chc",
        "ccc",
        'c', gregtech.api.enums.ItemList.Hull_EV.get(1),
        'h', gregtech.api.enums.ItemList.Hatch_Energy_EV.get(1));
} catch (Throwable t) {
    MyMod.LOG.error("[DIAG] MTEProductionLineAggregator registration FAILED", t);
    t.printStackTrace(System.err);
}

try {
    productionLineController = new MTEHatchProductionLineController(
        32121,
        "production_line_controller",
        "Production Line Controller Hatch",
        4);
    GameRegistry.addShapedRecipe(
        productionLineController.getStackForm(1L),
        "crc",
        "rgr",
        "crc",
        'c', gregtech.api.enums.ItemList.Hull_EV.get(1),
        'g', net.minecraft.init.Blocks.glass,
        'r', net.minecraft.init.Items.redstone);
} catch (Throwable t) {
    MyMod.LOG.error("[DIAG] MTEHatchProductionLineController registration FAILED", t);
    t.printStackTrace(System.err);
}
```

同时在CommonProxy类中添加字段声明：

```java
public static MTEProductionLineAggregator productionLineAggregator;
public static MTEHatchProductionLineController productionLineController;
```

## 二、MTEProductionLineAggregator 构造函数

```java
public MTEProductionLineAggregator(int aID, String aName, String aNameRegional, int aTier) {
    super(aID, aName, aNameRegional, aTier, 0, 
        new String[] { "Production Line Aggregator" });
}

public MTEProductionLineAggregator(String aName, int aTier, int aInvSlotCount, 
                                    String[] aDesc, ITexture[][][] aTextures) {
    super(aName, aTier, aInvSlotCount, aDesc, aTextures);
}

@Override
public MetaTileEntity newMetaEntity(IGregTechTileEntity aTile) {
    return new MTEProductionLineAggregator(mName, mTier, 0, mDescriptionArray, mTextures);
}
```

## 四、配方加载调用时机

在 `CommonProxy.java` 的 `init()` 或 `postInit()` 中添加：

```java
// Load production line recipes
try {
    ProductionLineRecipeLoader.loadRecipes();
    MyMod.LOG.info("[ProductionLine] Loaded {} recipes", 
        ProductionLineRecipeLoader.getAllRecipes().size());
} catch (Throwable t) {
    MyMod.LOG.error("[DIAG] ProductionLineRecipeLoader.loadRecipes FAILED", t);
    t.printStackTrace(System.err);
}
```

**注意**：必须在所有mod的Material和Item注册完成后调用，建议在 `FMLPostInitializationEvent` 中调用。

## 六、合成配方说明

### 产线聚合器（32120）
```
CCC
CHC  →  产线聚合器 ×1
CCC

C = EV级机器外壳 (Hull_EV)
H = EV级能量仓 (Hatch_Energy_EV)
```

### 控制器仓（32121）
```
CRC
RGR  →  控制器仓 ×1
CRC

C = EV级机器外壳 (Hull_EV)
G = 玻璃 (Blocks.glass)
R = 红石 (Items.redstone)
```

**注意**：合成配方可根据平衡性调整，这里只是示例。

## 七、关键注意事项

1. **构造函数参数**：`aInvSlotCount=0`，因为产线聚合器本身没有物品槽，所有输入输出通过总线/仓
2. **newMetaEntity**：必须正确实现，否则多方块结构无法创建
3. **getDescription**：返回的描述数组会显示在物品tooltip中
4. **异常捕获**：所有注册代码必须用try-catch包裹，防止一个注册失败导致整个mod崩溃
5. **日志**：注册成功/失败都要打日志，方便调试
6. **ID冲突**：32120/32121在GT5中是自定义ID范围（>32000），不会与GT5原生机器冲突
